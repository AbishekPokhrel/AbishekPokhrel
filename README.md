## What I do

I work on **medical imaging AI** at the intersection of **deep learning**, **computer vision**, and **clinical decision support**.

My focus is on building end-to-end systems that take medical images from raw scans to actionable insights — **segmentation → detection → report generation**.

---

## Current focus

- 🔬 **Research Assistant** at Towson University with Dr. Lei Zhang — MRI segmentation using **nnU-Net**
- 📝 Working toward a **MICCAI 2026** submission on prognostic chest X-ray representation learning
- 🧠 Building **BrainSeg AI** — brain tumor segmentation on BraTS 2023/24, deployed with **FastAPI + Docker + AWS**
- 🩺 Developing **NeuroLLM Report Engine** — RAG-based radiology report generation with **LangChain + ChromaDB + MIMIC-CXR**
- 🖥️ Presented **SegWorkbench**, a unified biomedical segmentation framework, at **SERA 2026**
